# MEMORA — AI-Powered Personalized Learning & Memory Platform

### Learn it. Understand it. Remember it.

MEMORA is an AI-powered study assistant designed to help students understand, revise, and remember study material more effectively.

## ✨ Features

- 🧠 Explain topics in simple language
- 📝 Summarize study material
- ❓ Generate quiz questions
- ✨ Improve student answers
- 😵 Explain difficult topics in a very simple way
- 🗣️ Teach It Back feedback
- 📅 Study Planner
- 🍅 Pomodoro Focus Mode
- ⚡ Quick Study
- 📎 Upload and study PDF, PPT/PPTX, TXT and images
- ⭐ Important Points generation
- 🧠 AI-powered learning assistance using Gemini

## 🤖 AI Integration

MEMORA uses the Google Gemini API to generate personalized learning content.

Different structured prompts are used for different learning tasks such as:

- Explanation
- Summarization
- Quiz generation
- Answer improvement
- Simplified explanations
- Teach-back evaluation
